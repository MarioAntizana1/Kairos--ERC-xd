# Glosario

> Estado: Vivo · Versión: 0.1 · Revisión: 2026-11-21 · Responsable: rol de Documentación

| Término | Definición |
|---|---|
| **ADR** | Architecture Decision Record; registro de una decisión de arquitectura. |
| **Baseline** | Distancia entre los centros ópticos de las dos cámaras. |
| **BVLOS** | Beyond Visual Line of Sight; vuelo más allá de la línea de vista. |
| **Calibración intrínseca** | Parámetros internos de una cámara: focal, centro óptico, distorsión. |
| **Calibración estéreo** | Rotación y traslación relativas entre las dos cámaras. |
| **ChArUco** | Tablero de calibración con cuadros y marcadores ArUco. |
| **Disparidad** | Diferencia horizontal de un punto entre las imágenes izquierda y derecha. |
| **DSR** | Design Science Research; marco de investigación basado en diseño. |
| **Epipolar** | Geometría que relaciona un punto en una imagen con una línea en la otra. |
| **Estéreo pasivo** | Dos cámaras sin proyector; la profundidad sale de la correspondencia. |
| **FMEA** | Failure Mode and Effects Analysis; análisis de modos de fallo. |
| **Genlock** | Sincronización de hardware entre cámaras para exponer al mismo tiempo. |
| **Global shutter** | Sensor que expone todos los píxeles a la vez. |
| **GNSS/RTK** | Posicionamiento satelital; RTK añade corrección centimétrica. |
| **IMU** | Unidad de medida inercial (acelerómetro + giroscopio). |
| **MAVLink** | Protocolo de comunicación con la controladora de vuelo. |
| **NED** | North-East-Down; sistema de coordenadas local. |
| **Nube de puntos** | Conjunto de puntos 3D (x, y, z, color). |
| **PCD/PLY** | Formatos de archivo de nube de puntos. |
| **Picamera2** | Biblioteca de captura de cámaras de Raspberry Pi. |
| **Rectificación** | Transformación que alinea las líneas epipolares horizontalmente. |
| **Rolling shutter** | Sensor que expone las filas secuencialmente; produce skew en movimiento. |
| **ROS 2** | Middleware de robótica (distro Jazzy en este proyecto). |
| **RTL** | Return to Launch; failsafe de la controladora de vuelo. |
| **SGBM** | Semi-Global Block Matching; algoritmo de disparidad de OpenCV. |
| **ToF** | Time of Flight; sensor que mide distancia por tiempo de vuelo de la luz. |
| **VIO** | Visual-Inertial Odometry; odometría visual-inercial. |
| **VLOS** | Visual Line of Sight; vuelo en línea de vista. |
| **Voxel** | Unidad cúbica para reducir la densidad de una nube de puntos. |
| **YAML** | Formato de configuración usado para calibración y parámetros. |
